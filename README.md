# Ultra Minimal React + Tailwind Starter

A super lightweight and stripped-down React + Tailwind starter if you hate files.

## Rundown

-   React + JavaScript
-   Vite
-   Tailwind
-   Minimal dependencies

## Setup

```bash
mkdir project
cd project
git clone https://github.com/edwjoh/ultraminimalistic-react.git .
npm install
npm run dev
```
